ম্যানেজার

ট্রিপ বানাবেন, মেম্বার যোগ/রিমুভ করবেন, সব contribution/expense ম্যানেজ করবেন।
Create trips, add/remove members, manage all contributions and expenses.

গ্রুপ মেম্বার

Manager-এর দেওয়া Join Code দিয়ে কোনো ট্রিপে জয়েন করবেন। শুধু ওই ট্রিপটাই দেখতে পারবেন।
Join a trip with the Manager's Join Code. You will only see that trip.

নোট: রোলটা শুরু করার জন্য। পরে আলাদা করে নতুন ট্রিপ নিজে Manager হিসেবে বানাতে পারবেন, আর ট্রিপ-ভিত্তিক রোল আলাদা হবে।
Note: This is your starting role. Later you can separately create your own trip as a Manager, and roles are per trip.
