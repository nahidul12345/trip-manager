কাজ

নোট: Manager চেঞ্জ: কোনো Member-এর পাশে "Make Manager" ক্লিক করলে সে Manager হবে, আর পুরনো Manager তখন Group Member হয়ে যাবে। Manager-এর অপশনগুলো তখন তার কাছে আর দেখাবে না। একমাত্র Manager থাকলে, আগে কাউকে Manager বানাতে হবে, তারপর সে Member হয়ে বের হতে পারবে।
Note: To change Manager, click "Make Manager" beside a Member. The old Manager then becomes a Group Member and will no longer see Manager options. If there is only one Manager, promote someone first, then the old Manager can leave as a Member.
