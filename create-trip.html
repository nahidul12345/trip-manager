ট্রিপ বানান

ট্রিপ বানানোর সময় Join Code দেখানো হবে না। ট্রিপ বানানোর পর ট্রিপ পেজে ঢুকলে Manager Join Code দেখতে পাবেন, আর সেই কোড দিয়ে মেম্বার জয়েন করবে।
The Join Code is not shown at creation time. After creating the trip, the Manager will see it on the trip page, and members will join with that code.
